# Методика: что наблюдается и что с этим делает эксперт

## Задача

Цифровое сознание в проекте — способность руководителя осмысленно управлять
деятельностью в цифровой среде: понимать данные и ограничения модели, ставить
цель, проверять рекомендации и сохранять ответственность за решение.

Программа **наблюдает действия** и складывает их в журнал. Оценку даёт человек
по протоколу. Автоматического балла нет и не будет.

## Шесть компонентов и наблюдаемые свидетельства

| Компонент | Что видно в журнале |
|---|---|
| **Знание** | открытие сведений о школе, источника и даты данных, просмотр расчётных последствий |
| **Осознание** | обоснование решения с упоминанием последствий для педагогов и классов |
| **Познание** | сравнение альтернатив, проверка совета помощника, обнаружение ошибки |
| **Предпочтение** | ограничения и цель заданы **до** выбора варианта (сравнивается порядок записей) |
| **Впечатление** | в обосновании описано, как совет и его подача повлияли на выбор |
| **Коадаптация** | после ошибки сформулировано изменение порядка проверки или границ делегирования |

## Как это устроено в программе

- каждый интерфейсный шаг пишет событие: `data_opened`, `assistant_checked`,
  `decision_made`, `explanation_written`, `error_detected`, `adaptation_note`;
- маркеры считаются из последовательности событий, а не из анкеты;
- порядок важен: если `constraint_set` записан после `decision_made`, маркер
  «Предпочтение» скажет «ограничения заданы после выбора»;
- журнал выгружается в JSON и CSV, профиль — вместе с прогоном.

## Чего программа не делает

- не ставит балл и не сравнивает участников;
- не влияет на расчёт: движок не читает профиль и журнал;
- не подсказывает пошагово в диагностическом режиме — проверки доступны, но не
  навязываются.

## Протокол исследования (черновик)

1. Входная диагностика: сценарий 2 (ограничение бюджета), одинаковые условия.
2. Экспериментальная группа проходит обучение по методике; контрольная получает
   общую управленческую памятку.
3. Итоговая диагностика: сценарий 1 и 3, другие сопоставимые ситуации.
4. Сравниваются: нарушения ограничений, сохранённые занятия, затраты, время
   решения, качество обоснования (экспертная оценка по заранее заданным
   критериям).
5. Участники — директора и заместители; студенты дают данные о тренажёре, но не
   о школьном управлении.
