# Цифровой двойник школы

**Демо: https://eagle1man.github.io/school-twin/** — открывается в браузере,
без установки и регистрации.

Рабочий прототип по концепции от 12.11.2026: модель ресурсов школы, в которой
руководитель принимает решения и сразу видит расчётные последствия, а
исследователь — сравнивает варианты и прогоняет серии экспериментов.

Открывается в браузере по ссылке (статический сайт, без сервера и установки).

## Что умеет

| Режим | Для кого | Что даёт |
|---|---|---|
| **Тренажёр** | директор, заместитель | три управленческих сценария, журнал действий, маркеры методики |
| **Песочница** | аналитик | меняет резерв, число отсутствующих, неделю, решение — видит последствия |
| **Эксперимент** | исследователь | серии прогонов: распределение по повторам, CSV для анализа |
| **Методика** | эксперт | что считается, как обеспечивается воспроизводимость, границы применимости |

Обязательные показатели (по концепции): непроведённые занятия, дополнительная
нагрузка, расходы, нарушения ограничений.

## Быстрый старт

```bash
cd D:\itотдел\school-twin
node tools/serve.mjs . 8081
# открыть http://127.0.0.1:8081/
```

Данные условные, генерируются детерминированно:

```bash
node tools/make-demo-data.mjs    # паспорт школы и сценарии
```

## Проверки

```powershell
node --test "tests/*.test.mjs"   # 22 теста движка и методики
node tools/e2e.mjs               # 16 проверок интерфейса против живого сервера
node tools/build-dist.mjs        # сборка сайта
node tools/check-public-data.mjs # в сборке нет ФИО и реальных данных
node tests/parity.mjs            # сверка с NetLogo (нужен results.csv)
```

## Как обновить демо

Одной командой (PowerShell, из папки проекта):

```powershell
powershell -File tools\publish.ps1 -Message "что изменилось"
```

Скрипт прогоняет тесты, собирает сайт, проверяет данные, коммитит и пушит.
Если поднят локальный сервер — добавьте `-WithE2E`, тогда проверится и браузер.

Вручную, по шагам (без `&&`: в Windows PowerShell 5.1 его нет):

```powershell
node --test "tests/*.test.mjs"
node tools/build-dist.mjs
node tools/check-public-data.mjs
git add -A
git commit -m "что изменилось"
git push
```

Pages пересобирается сам за ~30 секунд, статус: `gh run list --limit 1`.

## Состав

```
index.html            экран руководителя, три режима
assets/style.css      оформление
src/engine/           правила: расписание, ограничения, сценарии, метрики, журнал
src/ui/               интерфейс и графики (без зависимостей)
data/demo-school/     паспорт школы: JSON + CSV для импорта
data/scenarios/       три сценария из концепции
tests/                тесты движка, потока и сверки
netlogo/              порт правил в NetLogo и фикстура для сверки
tools/                сервер, генератор данных, дымовой прогон, сборка
docs/                 паспорт проекта, правила, приёмка, методика, публикация
```

## Чего здесь нет

- реальных персональных данных учителей — только коды;
- коэффициента, который улучшает результат по профилю участника;
- автоматической публикации: сайт собирается, выкладывает человек;
- сверки прогноза с фактом: для неё нужны данные реальной четверти
  (этап 5 в `docs/acceptance.md`).
