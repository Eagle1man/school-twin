# Паспорт школы: модель данных

Паспорт — единственный источник состояния школы. Всё, что не задано, получает
явное значение по умолчанию; молчаливых дыр нет.

## Файл паспорта (`data/demo-school/passport.json`)

```json
{
  "meta": { "name": "...", "version": "1.0", "asOf": "2026-11-16", "note": "..." },
  "calendar": { "weeks": 8, "days": 5, "slotsPerDay": 7 },
  "budget": { "limit": 20000, "hourRate": 600, "substitutionRate": 700, "overtimeFactor": 1.5 },
  "classes": [{ "id": "5А", "grade": 5, "students": 26 }],
  "teachers": [{ "id": "T-001", "name": "T-001", "subjects": ["math"], "maxWeekly": 18,
                 "hourRate": 600, "unavailable": [{ "week": 2, "day": 0, "slot": 3 }] }],
  "rooms": [{ "id": "101", "capacity": 30, "type": "general" }],
  "plan": { "5": { "math": 5, "rus": 5 } }
}
```

| Поле | Смысл | Ограничения |
|---|---|---|
| `calendar` | длина четверти и сетка уроков | `days × slotsPerDay` ≥ сумма часов плана |
| `budget.limit` | резерв на замены и переработку | расходы выше — нарушение `BUDGET` |
| `budget.hourRate` | стоимость часа | используется для доплаты за переработку |
| `budget.substitutionRate` | стоимость часа замены | используется при действии «замена» |
| `budget.overtimeFactor` | коэффициент доплаты за переработку | 1.5 = +50 % к ставке |
| `classes[].students` | численность | должна помещаться в помещение |
| `teachers[].subjects` | какие предметы ведёт | только они назначаются |
| `teachers[].maxWeekly` | недельная норма часов | выше — переработка |
| `teachers[].unavailable` | слоты недоступности | занятие в такой слот — нарушение |
| `rooms[].type` | `general`, `gym`, `computer`, `chem`, `phys`, `workshop` | физкультура, информатика, химия, физика, технология требуют своего типа |
| `plan[параллель][предмет]` | часов в неделю | сумма = нагрузка класса |

## Импорт из CSV

`data/demo-school/*.csv` — те же данные в плоском виде. Импорт не зависит от
формата, в котором школа ведёт учёт: колонки описаны в `passportFromCsv`
(`src/engine/model.js`).

```
classes.csv          id,grade,students
teachers.csv         id,name,subjects,maxWeekly,hourRate
plan.csv             grade,subject,hours
rooms.csv            id,capacity,type
```

Проверка совпадения JSON и CSV закреплена тестом «импорт паспорта из CSV
совпадает с JSON-паспортом»: расписания из двух источников имеют одинаковую
длину.

## Что проверяется при загрузке

Ошибки (расчёт не начнётся):

- нет классов, учителей или помещений;
- дублирующиеся идентификаторы;
- у класса нет учебного плана на его параллель;
- у учителя нет предметов или норма ≤ 0;
- план не помещается в неделю;
- предмет некому вести (нет ни одного учителя с этим предметом).

Предупреждения (расчёт идёт, но повод посмотреть данные):

- спрос по предмету выше суммарной нормы квалифицированных учителей;
- помещений меньше, чем одновременных классов.

## Демонстрационный паспорт

12 классов (5–11), 24 учителя, 22 помещения, четверть 8 недель, сетка 5 × 7.
Недельная нагрузка по плану — 317 ч. Данные синтетические: ФИО нет, только коды
`T-001…T-024`, ставки и нормы — параметры, а не факты о конкретной школе.
